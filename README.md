### 🚀 Featured Project: Rooznabeh (Ad Platform)

A highly scalable, production-ready advertising platform built from scratch, focusing on high performance and enterprise architecture.

*   **Architected a scalable backend** using **.NET 9** based on **Clean Architecture, CQRS (MediatR), and DDD** principles.
*   **Optimized database performance** (PostgreSQL) using **PgBouncer** for connection pooling, **Dapper** for high-speed read operations, and advanced indexing (including **GIN** for Full-Text Search).
*   **Implemented a robust caching & messaging layer** using **Redis** for high-traffic endpoints and **SignalR Redis Backplane** for scalable, multi-server real-time chat.
*   **Containerized the entire infrastructure** (API, DB, Redis, MinIO, Seq, Prometheus, Grafana, Nginx) using **Docker & Docker Compose**.
*   **Secured the application** by implementing **OWASP Security Headers**, advanced **Rate Limiting**, and secure secrets management.
*   **Set up full observability** using **Prometheus & Grafana** for metrics, and **Serilog & Seq** for centralized structured logging.
*   **Built a robust CI/CD pipeline** using **GitHub Actions** ensuring code quality with over **570 passing tests** (Unit & Integration).
*   **Developed a PWA-enabled React frontend** with code-splitting, lazy loading, and offline capabilities.
